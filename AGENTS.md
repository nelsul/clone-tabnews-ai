# AGENTS.md

## Project

`clone-tabnews-ai` is an implementation of [TabNews](https://tabnews.com.br) built with AI agents, following the [curso.dev](https://curso.dev) course.

## Stack

- Next.js with the App Router; exact versions are pinned in `package.json`
- Plain JavaScript (no TypeScript), plain CSS (no CSS framework)

## Conventions

- Keep it minimal: the simplest code that follows modern Next.js patterns (App Router, Server Components by default).
- Verify changes with `npm run build`.
